# QLP review of batches 06–10

From the workspace root run `python -B sky/mixed-154-2026-11-24/batch06/review_lane.py` with NumPy, SciPy, Astropy and Matplotlib. Append a batch number to run one group. On another checkout pass `--root PATH` with the input workspace root. The script keeps the QLP helpers with the analysis and has no imports from the earlier review directories.

Inputs are the colocated batch CSVs, original QLP FITS under `sky/data/qlp-sb-p20-60`, the archived window JSONs under `Astra/made/binary-exploration-2026-11-04/bulk-results`, and the sector- and camera-specific screening table at `sky/mixed-fold-2026-11-24/cadence-controls/flagged-exposures.csv`. The script takes the FITS times as BTJD. It uses finite paired SAP and available KSPSAP_FLUX or DET_FLUX, requires QUALITY = 0, and excludes listed sector-camera-cadence coincidences.

Event panels show raw SAP in blue and QLP-corrected flux in orange, against separate local baselines, with the scan core shaded. Each measured depth is the median core deficit relative to a line through the median flux in each wing. Each event table stores counts, nominal sampling fractions, core spacing, wing scatter and flagged-exposure intersections. A covered prediction requires at least 65% sampling in the core and both wings and no core spacing over the larger of 0.025 d and 15% of the duration. Finite measurements at incomplete windows are descriptive, since interrupted trends can yield large formal losses.

Gaia, pilot and fold-screen periods are tested as available. Selection of a phase maximizes distinct sectors near archived event times, with preference for an epoch of comparable width to the anchor. Because this conditions on the events themselves, independent covered event predictions and morphology matter more than agreement on the seeds. These Gaia phase trials use photometric epochs. No prediction here assumes that Gaia periastron is the dip center. Optional hypotheses and short-fold trial CSVs record added tests. Per-sector Lomb–Scargle peaks cover 0.125–14.3 d and selected phase panels use each sector's first usable cadence as reference.

Each batch has an individual disposition table, archived window plots, observed and predicted measurement tables and auxiliary period diagnostics. Cross-target windows within 0.35 d in the same sector are listed in the shared-window table and treated as useful controls when the surrounding shapes, data gaps or camera geometry agree.
