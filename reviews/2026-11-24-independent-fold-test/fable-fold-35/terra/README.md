# Terra independent visual review

Reviewed all 35 batch apertures in the four supplied groups, without consulting the other reviewers' assessments. `assessment.csv` records the morphology call and caveats for each target. The 22 `repeated` calls are visual evidence of multiple eclipse-like depressions in the aperture, not proof of host, period, astrophysical origin, or catalogue novelty. Two objects show a single relatively clean event, two show an extreme single excursion requiring background investigation, eight are uncertain, and one has no clear deep event. This is not a formal adjudication of the numerical pilot outcome.

For each TIC, `<tic>.png` shows the original cached time series after per-sector two-day running-median normalization, the supplied fold, and a broad independent box-least-squares (BLS) fold. PDC points are black, SAP blue, and the red curve is the median PDC in phase bins. `<tic>-events.png` overlays candidate event cutouts from PDC (colored lines) and SAP (black points). Contact sheets are included for review. Times are BTJD, flux residuals are parts per thousand. No pixel localization or background restoration was performed. Median filtering may distort wide events; only finite positive SAP/PDC samples were retained, so large negative flux excursions are truncated, notably 52157743 and 218233922. The plots do not establish a source or rule out contamination.

`clocks.csv` contains coarse BLS grid maxima over 1–15 d with fixed 0.08, 0.16, and 0.30 d boxes, without alias validation or uncertainty; these are hypotheses only, and harmonics, period-grid phase drift, long events and single events can mislead. No claim of an exact ephemeris is made. `event_candidates.csv` is a finder aid: groups of at least three below -10 ppt with nominal bracketing and five times sector scatter. Its counts can include split events, artifacts and edge effects, and miss real events. Event minima are sample minima, not fitted centers. The independent visual assessments use the full plotted data and event cutouts, not these counts alone.

Run `python /path/to/fable-fold-35/terra/review.py`, then `events.py`, `cutouts.py`, and `assess.py` in that directory; scripts resolve input and output paths relative to themselves and can be launched from any working directory. Set `TESS_FOLD_CACHE` to the directory of cached TIC-sector NPZ files or pass `--cadence-cache /path/to/cadences` to each of the first three scripts (the option takes precedence). If neither is set, the default is `sky/data/fable52-ffi-tce-2026-11-24/cadences` relative to the checkout; the cache must be supplied separately if absent. `assess.py` consumes the generated tables and does not read the cache. Requires numpy, pandas, scipy, astropy, matplotlib and Pillow. Inputs are `batch.csv` and cached per-sector NPZ files. No quality flags or pixel/background data were available in those cached arrays.
