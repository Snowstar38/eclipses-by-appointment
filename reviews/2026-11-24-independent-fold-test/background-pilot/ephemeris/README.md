# Known asteroid geometry for a TESS event

`intercept.py` takes a local or public SPOC two-minute target pixel FITS, an event center in BTJD and a half-window in hours. It reports whether an asteroid's nominal center crosses collected, background and stellar pixels, how close it comes to each mask, and whether any quality-zero exposure midpoints sample the crossing. A bright source can contribute substantial light outside the pixel containing its center. The photometric effect depends on the point-spread function, source brightness and how the pipeline estimated background.

Install `numpy`, `astropy` and `requests` with Python 3. A live example for the 90-minute Vesta window is

```sh
python intercept.py https://stpubdata.s3.us-east-1.amazonaws.com/tess/public/tid/s0108/0000/0006/3031/4437/tess2026250081459-s0108-0000000630314437-0310-s_tp.fits --btjd 4312.17265243838 --half-hours .75 --margin-pixels 2 --out event.json
```

Add `--track FILE.csv` to compare independent sky positions. The file needs `utc,ra_deg,dec_deg` and may include `tic`. UTC must be spacecraft exposure time. Positions must be astrometric ICRS/J2000 in degrees. Only points in the requested time window enter the comparison. To reproduce the full-frame comparison, use `--half-hours 1.08333333333 --track ../wide-track.csv`. A particular numbered asteroid or designation can be checked independently of the cone result with `--object 4`. The JSON includes both the catalogue list and all attempted Horizons results.

## Method and limits

1. Convert the TPF mid-exposure timestamps to spacecraft UTC using `TIME - TIMECORR + BJDREFI + BJDREFF` in TDB, then Astropy's TDB-to-UTC conversion. Interpolate the correction at the requested window boundaries and midpoint. Report the number of good exposures and maximum gap. Ephemeris geometry applies throughout the time window, including gaps.
2. Query the SkyBoT asteroid catalogue at the midpoint for observer `@tess`. The cone encloses the tangent-plane stamp corners after expansion by the advisory margin, plus a speed allowance of 120 arcsec/hour times the half-window. For a different speed bound, pass `--speed`. A faster object can traverse the stamp outside this search. An unavailable spacecraft query triggers a geocentric cone with 0.3 degree additional radius, adjustable with `--geo-pad`. Nearby bodies can exceed this parallax allowance. A network or server failure, an empty HTTP body or an unrecognized response receives an unavailable status. [SkyBoT cone service](https://ssp.imcce.fr/webservices/skybot/api/conesearch/) · [Observer conventions](https://ssp.imcce.fr/webservices/skybot/howto/conesearch/)
3. Retain all catalogue rows, including approximate visual magnitude, position uncertainty, apparent rates and distance from the cone center when provided. By default, propagate up to eight candidates through magnitude 19, brightest first. Candidates with unknown magnitude are eligible after the known magnitudes within the limit. Mandatory IDs take precedence. Change the limits with `--max-mag` and `--max-objects`. These are computation limits. SkyBoT covers catalogued asteroids and makes no completeness guarantee for this test. A faint catalogued body near the aperture can coexist with a brighter crossing.
4. Query JPL Horizons for astrometric ICRF directions from the TESS spacecraft, `CENTER=500@-95`, on a grid no coarser than five minutes and at the measurement epochs. The report includes each query URL and response hash. Map each direction through the APERTURE extension's WCS. Intersect the piecewise-linear track with closed unit squares centered on zero-based detector pixels. The mask bit values are 1 for collected, 2 for optimal stellar aperture and 4 for background. Distances are to the nearest pixel-square edge in detector pixels. The first and last time of each potentially intersecting segment bracket the crossing. Shorter ephemeris steps are available with `--step-minutes`. Fixed WCS, pointing jitter, measured astrometric uncertainty, finite exposure and PSF extent limit this test near boundaries. Formal error propagation and an empirical wing model would require additional data. [JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html) · [TESS Data Products Description, §5.2.3](https://ntrs.nasa.gov/api/citations/20205008729/downloads/EXP-TESS-ARC-ICD-TM-0014-Rev-F_v2.pdf)
5. The default two-pixel advisory margin expands the candidate cone and labels un-crossed mask edges within two pixels as `nearby`. `center_hit` records a direct center-line intersection. `distant` means outside that margin and `unavailable` denotes a mask without pixels or a missing calculation. Set `--margin-pixels 0` for the unexpanded stamp footprint. Even bright wings outside the selected margin can be detectable. Search coverage is reported as bounded TESS search, partial or unavailable. A fully propagated returned list still excludes unknown bodies and bodies outside the cone model.

## Reproducibility

The command runs independently with a target pixel file and the three Python packages. It creates a cache beside the script, configurable with `--cache`. Queries run sequentially. Simultaneous commands sharing the cache serialize JPL requests. Server results are cached by exact query URL. If a service failed during a run, choose a new cache directory to re-query it. Local or downloaded FITS and raw service bodies are SHA-256 hashed. An unavailable online service leaves a qualified JSON result when the input TPF is available.

`geometry-queries.zip` contains the raw catalogue and ephemeris bodies behind these seven reports, with URL and hash metadata for each. To replay the receipts, extract the ZIP in a fresh cache directory and pass that directory to `--cache`, using the original query arguments and the local TPF. Downloaded pixel FITS can be recovered separately using the public URLs above. Later catalogue and orbital solutions, or transient server coverage, may differ.
