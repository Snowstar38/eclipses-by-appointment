# Independent helper final audit

At the lead's numeric freeze, independently checked all ten queue identities, result rows, reports, fitted measurement files and historical images. All ten are complete: nine confirmed and one probable (TIC 374589618, unresolved localization). `helper/final-audited-hashes.json` records exact SHA256 hashes for the 40 reports/measurement/raw artifacts and queue, results, geometry JSON and geometry script; it is the definitive list of files examined here. `helper/final_check.py` reproduces numeric/report checks. `helper/attribution-audit.json` records hashed historical images and source data, with pixel distances and aperture depths. The raw-event montage and all ten historical images were visually reviewed.

Independent weighted linear regressions were recomputed from selected measured midpoints, input timing errors and same-kind orbital cycles. All ten period values agree within 5e-13 days and reference epochs within 1.2e-10 days; formal/inflated errors also reproduce. Counts, numerical result fields, report period, errors, epochs, geometry and every event row matched the saved artifacts. `helper/regression-audit.json` contains input hashes and results; `helper/regression_audit.py` reproduces them. Four half-spacing cases use a single orbital parity; usable fits of the opposite parity remain documented but do not enter the timing regression. Singular fits marked unusable are excluded. Historical event centers are predictions, not timings. Errors remain conservative fit allowances rather than calibrated coverage.

The Gaia SB1 script reads each source's own 15-element correlation vector, forms the lower-triangle correlation matrix in period, gamma, K, eccentricity, omega, periastron epoch order, selects indices 0, 3, 4, 5 and propagates a finite-difference conjunction Jacobian. All ten full matrices have positive minimum eigenvalues (approximately 0.000003 to 0.0281); this checks arithmetic consistency with the recorded vector convention, not independent validation of Gaia's model. The geometry is approximate, not a fitted binary solution; covariance propagation is linear and is not an arbitrary veto.

Key limitations: TIC 336856559's crowded field has loss centroid 0.211 pixel from target and bright capable neighbor 2.26 pixels from deficit; 1/3/5-pixel depths 99.7/54.2/27.3 ppt demonstrate aperture dependence, but do not determine the exact cross-sector QLP depth difference. TIC 42960522's closest capable neighbor lies 1.55 pixels from the deficit. TIC 374589618's source assignment remains unresolved: a capable neighbor is 0.67 pixel from deficit with an approximate 79% intrinsic eclipse requirement, and centroid uncertainty is not calibrated. Its low-S/N undersampled cycle-2 depth is overstated by the fitted shape, excluded from the selected parity. TIC 146878534 has clean sector-33 events, whereas sector-87 baselines and scatter limit inference from apparent depth changes. Same-photon TESScut extraction checks reduction robustness, not independent observation. Full descriptions and source hashes are in `helper/INITIAL-AUDIT.md` and `helper/attribution-audit.json`.

No mismatches were found in the audited frozen files. Lead must regenerate the encompassing SHA256SUMS after this helper audit is written; any subsequent change to an audited file invalidates the corresponding helper hash and requires recheck.

An independent recomputation of all ten SB1 mass functions and substitution of each reported minimum companion mass into f(M)=M2^3/(M1+M2)^2 agree to 6e-17 solar masses; all geometry photometric periods match the measurement files exactly.
