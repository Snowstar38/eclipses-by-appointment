Three ellipsoidal systems, one plausible system, one neighbour signal, and seven unvetted candidates add nothing to the confirmed/probable count. TIC 416285595 has a pipeline depth mismatch and remains confirmed with caveats under the returned classification. TIC 319185391 is treated as plausible outside the count, following the batch verdict despite stronger prose in vet11.
