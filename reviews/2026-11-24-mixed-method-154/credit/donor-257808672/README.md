# Prior credit for TIC 257808672

**TIC 257808672 was already catalogued as a variable. The checked survey records contain no prior explicit eclipse classification or individual eclipse annotation.** Kostov et al. independently flagged this star as an eclipse candidate in their machine-selected Table 2. The new project entry validates that candidate in an already catalogued variable. [Host record and prior candidate](../../host-257808672.md) This check establishes what the listed records say.
