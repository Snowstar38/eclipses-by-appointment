# SPOC eclipse signals and source reassignment

This release adds 4 probable photometric eclipsing binaries. The search started with 267 previously unadjudicated SPOC two-minute threshold-crossing-event apertures with independently recovered periodic dips. The first frozen batch contained 125. The screening table records the 267 apertures measured by the date of this export. Each source record identifies the public signal and prior machine selection where applicable.

The pixel measurements compare in-eclipse cadences with local out-of-eclipse flux on both sides of each event. Gaia DR3 scene fits test the designated star and flux-capable alternatives within 90 arcsec. The independent FFI extraction uses a 1.5-pixel-radius aperture at the proposed host. The retained products give flux depths for each adequately sampled cycle, including low-significance cycles. The disposition table's event count uses S/N of at least four. The period fit uses deficit-weighted event midpoints in the host's archive light curve. BTJD is BJD on the TDB time scale minus 2457000. The listed period error is the formal regression error. TESS data underlie both photometric reductions.

Table 2](https://vizier.cds.unistra.fr/viz-bin/VizieR?-source=J/ApJS/279/50/table2), [the live Villanova catalogue](https://tessebs.villanova.edu/), [HEASARC VSX](https://heasarc.gsfc.nasa.gov/W3Browse/all/aavsovsx.html), [SIMBAD](https://simbad.cds.unistra.fr/simbad/), [NASA ADS](https://ui.adsabs.harvard.edu/), [Tang et al.](https://doi.org/10.3847/1538-3881/ae18c4), and the [spectroscopic compilation](https://doi.org/10.3390/universe12110358). The per-source records give additional catalogue names, coordinates, identifiers, product URLs, SHA-256 hashes, and ADS query results.
