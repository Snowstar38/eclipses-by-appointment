## Reproduce the propagation

Run `python orbit.py` with NumPy, Astropy, and Matplotlib. The default inputs are the [Gaia NSS orbit row](gaia-orbit.csv), the [Gaia source epoch](gaia-source.csv), and the [two-minute SPOC fitted eclipses](spoc-eclipses.csv). The script restores Gaia's column-major triangular correlation vector in the documented 15-parameter order for this solution's bit index of 65535 and uses the relevant nine-dimensional marginal covariance. It takes 80,000 multivariate-normal draws from the published formal solution. These intervals propagate the catalog's uncertainties and preserve the correlations. They do not include NSS model systematics, possible changes in the orbit, or detailed eclipse-profile uncertainties. [Gaia NSS table and covariance conventions](https://gea.esac.esa.int/archive/documentation/GDR3/Gaia_archive/chap_datamodel/sec_dm_non--single_stars_tables/ssec_dm_nss_two_body_orbit.html)

For each draw the astrometric coefficients give the inclination and projected sky position through the eccentric anomaly. The spectroscopic C and H coefficients select the radial branch, with nominal arguments of periastron of 151.53° from the astrometric projection and 151.01° from C and H. The code locates the local minimum in each line-of-sight hemisphere by solving the derivative of squared sky separation. It checks the curvature and hemisphere, then converts the anomaly to mean anomaly and elapsed orbital time. The periastron offset is added to Gaia's J2016.0 TCB epoch and converted to TDB before subtracting 2457000. At the observed orbit number, the time conversion is much smaller than the formal timing uncertainty.
