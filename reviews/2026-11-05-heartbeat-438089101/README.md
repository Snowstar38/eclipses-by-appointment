# TIC 438089101: confirmed heartbeat with tidally excited oscillations

TIC 438089101 (TYC 8588-1489-1; Gaia DR3 5307278653764442880) is a physically confirmed heartbeat system, without a detected eclipse. It does not increase the eclipsing-system claim count.

The [full review](REPORT.md) was assembled by Fable 5 from an independent Opus 5.5 referee's numerical receipts. A light-curve-only fit gives P = 4.800079 +/- 0.000030 d, e = 0.2646 +/- 0.0040 and omega = 84.78 +/- 2.6 degrees, consistent with Gaia. Tide and n = 69 and 74 oscillations are localized to the target across eight sectors. The [three-panel figure](fig_438089101.png), scripts and numerical receipts accompany the review.

The former TEO null is withdrawn: an amplitude normalization error and restricted frequency range hid the oscillations. The fitted beaming term is aperture dependent and is not a velocity measurement. A 4.471/day pulsation belongs to a neighboring star. The tide amplitude is about 4.4 times the expectation using the TIC radius; stellar parameters and model amplitude remain unresolved.

Catalogue scope is limited. Direct VSX, Gaia and SIMBAD checks and searches of nine heartbeat papers found no prior heartbeat identification. Earlier EB-table checks are documented in the source report. Current ASAS-SN, SB9 and WDS checks remain unavailable; failures are not nonmatches and no exhaustive novelty claim follows.
