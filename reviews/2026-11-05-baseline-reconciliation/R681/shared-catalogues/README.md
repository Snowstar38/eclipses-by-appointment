# Central catalogue check

`run_catalogues.py --queue PATH --queue-sha256 HASH --local-only` checks the exact frozen queue, cached Chopard public v1.2.0 tables, and the locally cached heartbeat papers without network access. Omit `--local-only` to run the bounded catalogue queries. The explicit SHA256 must match the queue bytes; a changed queue cannot silently reuse receipts. The runner refuses duplicate TICs, inconsistent identifiers, missing coordinates, and previously saved receipts from another queue. Rerunning is resumable: each successful response is reused only if its stored raw-file hash, query, and queue hash match. Failed queries remain `unavailable`, never negative evidence.

Network scope: 60-arcsec VSX and ASAS-SN cones; 5-arcsec cones in Prsa 2022, IJspeert 2024, and two Kostov 2025 vetted tables; exact Gaia DR3 variable EB and NSS rows; exact Gaia DR3 identifier lookup in SIMBAD. Queries are sequential with a short delay. No paid API or bulk download is used. Raw responses and source/queue hashes are retained. `coverage-matrix.csv` is a screening aid; its positive or negative flags do not classify the light curve or settle nearby-source attribution. The Chopard comparison only covers cached public v1.2.0 tables; later releases and embargoed identities remain unknown.

The local heartbeat gate parses Callahan+2025 `SBTABLE.full.tex` from the cached arXiv source and verifies all 112 rows. A `True` eclipse flag is a prior-eclipse alert. A `False` flag is not evidence against an eclipse found in the current photometry. The eight other cached heartbeat papers are checked by exact TIC-number token; this does not clear papers keyed only by OGLE or KIC identifiers.
