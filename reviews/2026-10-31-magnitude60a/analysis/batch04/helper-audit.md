# Independent helper audit, batch 04

Scope: exactly the ten batch04 queue TICs. Inspected raw-contact.png and diff-contact evidence, target-specific numeric event lists, period selection, c6/c7 SAP metadata, Gaia identities and the saved historical difference/cutout identities. Historical material is reused after identifying and hashing files; it is not an automatic screening pass. No public files changed.

`helper-refit.py` independently optimizes each saved raw-flux event window using bounded least squares and independently solves the weighted linear ephemeris from the actually measured selected event midpoints. `helper-numerical-audit.json` contains all ten results and SHA256 hashes of each input measurement and raw-window file. All fitted periods, epochs and period errors reproduce within 6e-13 d, 1e-10 d and 5e-16 d respectively. The per-event error is max(formal center covariance, half cadence), followed by reduced-chi-square inflation where applicable; it is not a calibrated total uncertainty. Piecewise trapezoid reoptimization from a different starting point moved an individual center by up to 0.0152 d for TIC 419573851 and 0.0151 d for 124007093; model/baseline sensitivity is material and must not be hidden by the formal period error. The regression reproduction uses the saved measured midpoints, not predictions. For 362822264 and 314047448 two observed events constrain the period conditional on the historical integer cycle counts; they do not by themselves exclude all aliases.

All ten historical periods in the measurements match the actual chunk-specific c6/c7 SAP records, and each geometry Gaia source ID matches targets-selected.json. TIC 309558046 search full branch is 13.082944 d while SAP branch is 6.541211 d. Even half-period cycles are the deeper primary, approximately 27 ppt versus 17 ppt for odd cycles; same-kind even events yield 13.0830020618 d. Do not use the half-period as the orbital period or mix alternating eclipse kinds. Other epochs are selected repeating eclipses by convention, without independently established deeper identity. Geometry code uses Gaia NSS identity, eccentric conjunction, period and full SB1 correlation submatrix; linear covariance and approximate radius/mass duration are descriptive, not a sigma veto or complete physical model.

`helper/pixel-identity-audit.json` records all ten historical difference-image hashes, original cutout hashes, centroid offsets, PSF residuals and capable neighbors. A neighbor's required source-intrinsic fractional eclipse is not directly comparable with a blended pixel fractional deficit. Source centroids are uncalibrated estimates, not formal exclusion radii; alternative TESScut reduction uses the same photons.

In particular the 314 result is invalid for inference because local baseline behavior dominates.
