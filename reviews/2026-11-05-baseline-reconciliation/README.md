# Baseline reconciliation evidence

The 49 directories R676–R724 contain the accepted physical-review reports and compact supporting measurements and figures. [C57](C57/REPORT.md) preserves the existing review identity while documenting its reassessment; its [catalogue checks](C57/catalogue-recovery/REPORT.md) and [saved measurements, figures, and original review](C57/source-evidence/) are included. The original QLP cache was unavailable for an independent rerun, and raw FITS are not included. C57 remains limited by host ambiguity; its scoped catalogue nonmatch is not exhaustive proof of novelty.

The [17 prior-known removals](known-removals/baseline-delta.csv), [accounting table](known-removals/revised-identity-accounting.csv), [addendum](known-removals/ADDENDUM.md), and primary-source extracts document the correction to the new-claim count. A prior-known classification does not invalidate the physical recovery. The baseline reconciliation is 917 minus 17 prior-known systems plus 13 accepted additions, or 913; the 250 period-free reviews are a separate evidence register and add no new discovery claims.

[Provenance hashes](provenance-sha256.csv) record each original file and its exported bytes. Public text has local paths and personal references redacted and some report links adjusted, so the two hashes can differ. Other SHA-256 lists or hashes inside historical receipts refer to original source files, not necessarily the transformed public copies; use the public provenance table to verify exported bytes. Reports and scripts may reference omitted external data or historic caches, and this package does not contain bulk FITS or archives.
