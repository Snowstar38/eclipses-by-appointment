# Q031-Q040 lead audit

The batch queue is the sealed original priority ranks 181-190. The lead rechecked the source-packet SHA-256, cached detector-result SHA-256, and every used QLP FITS SHA-256 before constructing raw context for all ten targets. `lead_context.py` produces every-sector raw SAP plots, selected-window SAP/KSPSAP zooms, actual quality-zero positive-flux time coverage, and numeric local series. `lead_flag_diagnostics.py` measures actual core endpoints and nearby gaps. The selected detector times were used as search windows, never as measured eclipse centers. `lead_timing.py` and `lead_alias_geometry.py` provide bounded timing, conditional integer-alias comparisons, actual-cadence short-alias nulls, and source-specific Gaia conjunction calculations for Q031 and the separate Q036 off-target lead.

Q031 is the sole queued target with a confirmed eclipse interpretation in this batch. Three same-kind raw events and a different-kind S31 event are visible. Adjacent 42/44 long-baseline counts disagree with the S31 main event by roughly a day; the 43-cycle count agrees within 0.0042 d. An actual S97 P/2 core is flat within local noise, with full cadence coverage. Target-centered WCS difference photometry in three sectors and a distant faint nearest Gaia neighbor support source ownership. Gaia SB1 conjunction is close to the measured main event; the rounded 42.54 d photometric period and event epoch are not precision ephemerides. Same photons under alternate extraction are counted once.

Q036 contains a real seven-event ~6.1464 d eclipse train in the blended aperture, including one unflagged S85 event found in raw context. It is assigned to a neighboring Gaia source by repeated sky-corrected difference-pixel peaks, source-relative centroids, disjoint aperture-strip deficits, and a feasible neighbor flux budget. The queued target's Gaia 20.143 d orbit is incompatible with that clock. The queued target attribution is REFUTED, and `OFF-TARGET-LEADS.json` preserves coordinates, conditional clock, and evidence references for a separate follow-up. This does not rule out independent binarity of the queued target. Both spatial cutouts have similar WCS orientation and TESS PRF overlap, which limit precision localization.

Q032-Q035 and Q037-Q039 selected dip windows are explained by actual gaps, level changes, and long baseline slopes. In particular, five targets on different CCDs have selected S94 minima at BTJD ~3874.8-3874.9, precisely at gap boundaries and with similarly asymmetric recovery. This common timing is supporting evidence, while each report records its own actual endpoints, gaps, and morphology. Q040 raw SAP shows smooth large-amplitude multi-sector waves whose flagged centers are on slopes rather than isolated eclipse cores; the S41 slope is suppressed in KSPSAP, so its astrophysical mechanism is unresolved. The verdicts concern the selected eclipse claims; other independent signals are not excluded.
